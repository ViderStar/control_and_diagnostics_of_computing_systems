# Контроль и диагностика вычислительных систем

## О дисциплине

Курс посвящён методам обеспечения надёжности цифровых систем посредством тестирования и диагностики неисправностей. Изучаются как классические детерминированные алгоритмы построения тестов, так и современные вероятностные и аппаратные подходы (BIST).

### Основные темы

| Раздел                                                                 | Что изучается                                                                                          |
| ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Моделирование неисправностей**            | Stuck-at-0/1, coupling faults, pattern-sensitive faults                                                            |
| **Генерация тестов (ATPG)**                             | Детерминированные алгоритмы построения тестовых воздействий |
| **Псевдослучайное тестирование**            | LFSR, M-последовательности, управляемые случайные тесты                 |
| **Тестирование памяти**                              | Маршевые тесты (March), Walking 0/1, MBIST                                                            |
| **Проектирование для тестирования (DFT)** | BIST, граничное сканирование                                                                  |

### Цели курса

1. Понимать модели неисправностей цифровых схем и памяти
2. Строить тесты для комбинационных схем вручную и автоматически
3. Применять LFSR для генерации псевдослучайных последовательностей
4. Выбирать оптимальные маршевые тесты для ОЗУ
5. Проектировать системы встроенного самотестирования (BIST/MBIST)

## Теория лабораторных работ

### 📘 [ЛР №1: Метод активизации одномерного пути](labs_info/lab1_theory.md)

**Тема**: Базовый метод построения тестов для комбинационных схем

**Ключевые понятия**:

- Константные неисправности (stuck-at-0, stuck-at-1)
- Условия наблюдаемости и активности пути
- Характеристические неисправности
- Детерминированная генерация тестов

**Применение**: Малые критичные схемы, учебные цели, базовый алгоритм САПР

---

### 📗 [ЛР №2: D-алгоритм (метод многомерного пути)](labs_info/lab2_theory.md)

**Тема**: Систематический метод автоматической генерации тестов

**Ключевые понятия**:

- Кубическое представление (0, 1, x, d, D)
- Сингулярные кубы, D-кубы, примитивные D-кубы
- D-проход (пропагация неисправности)
- Фаза консистентности (обратный ход)

**Применение**: Промышленные САПР, автоматизированное тестирование, ATPG-инструменты

---

### 📙 [ЛР №3: Генераторы тестов на базе LFSR](labs_info/lab3_theory.md)

**Тема**: Псевдослучайное тестирование с использованием регистров сдвига

**Ключевые понятия**:

- LFSR (Linear Feedback Shift Register)
- М-последовательности (максимальной длины)
- Характеристический полином (примитивный, неприводимый)
- Свойства М-последовательностей (баланс, серии, автокорреляция)
- Оптимизация начального состояния (seed)

**Применение**: Встроенное самотестирование (BIST), генерация тестов на кристалле

---

### 📕 [ЛР №4: Тестирование ОЗУ — классические неисправности](labs_info/lab4_theory.md)

**Тема**: Специфические неисправности оперативной памяти и маршевые тесты

**Ключевые понятия**:

- Адресные неисправности (AF)
- Константные неисправности ячеек (SAF)
- Неисправности взаимного влияния (CFin, CFid)
- Маршевые тесты (MATS, March C, Walking 0/1)
- Временная сложность (O(N) vs O(N²))

**Применение**: Тестирование SRAM/DRAM, MBIST (Memory BIST), производственный контроль

---

### 📔 [ЛР №5: Тестирование ОЗУ — кодочувствительные неисправности](labs_info/lab5_theory.md)

**Тема**: Неисправности, зависящие от содержимого соседних ячеек

**Ключевые понятия**:

- Кодочувствительные неисправности (NPSF)
- Пассивные NPSF (блокировка изменения)
- Активные NPSF (непреднамеренные переходы)
- Модели соседства (K3, K5, K9)
- March PS и другие усиленные тесты

**Применение**: Тестирование памяти с малыми технормами (< 10 нм), 3D NAND

---

### 📒 [ЛР №6: Управляемые вероятностные тесты (CRT)](labs_info/lab6_theory.md)

**Тема**: Управляемая генерация случайных тестов по метрикам различия

**Ключевые понятия**:

- THD / TCD (суммарные расстояния)
- Расстояние Хэмминга и декартово расстояние
- Выбор лучшего кандидата (жадный алгоритм)
- Оценка покрытия stuck-at на схеме

**Применение**: Улучшение эффективности псевдослучайных тестов при фиксированной длине

---

### 📓 [ЛР №7: FAR и OCRT (управляемые тесты)](labs_info/lab7_theory.md)

**Тема**: Быстрые и конструктивные методы управляемого тестирования

**Ключевые понятия**:

- FAR (centroid pattern)
- OCRT (оптимальный управляемый тест для \(N=2^m\))
- Матрица масок и перестановка столбцов
- Сравнение покрытия на схеме

**Применение**: Быстрое формирование разнообразных тестов без дорогостоящего перебора

| ЛР7 (FAR/OCRT)                      | Низкая–средняя | Вероятностное     | Высокая             | Быстрые управляемые тесты |

## Связь между лабораторными

```
ЛР1: Базовый метод тестирования
  └──► ЛР2: Расширение до многомерных путей (кубы)
         └──► ЛР3: Оптимизация через LFSR (BIST)
               └──► ЛР6: Управляемые вероятностные тесты (THD/TCD)
                      └──► ЛР7: Конструктивные FAR/OCRT

ЛР4: Классические неисправности памяти
  └──► ЛР5: Расширение до кодочувствительных неисправностей
```
